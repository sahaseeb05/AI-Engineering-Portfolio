## 🚀 Highlighted Project: AegisNIDS

**AegisNIDS** (Network Intrusion Detection System) combines Artificial Intelligence with Cyber Defense to detect and classify complex malicious network traffic.

### Key Features:
* **Multi-Class Threat Taxonomy:** Detects Normal traffic along with specific threats like **DoS**, **Probe**, **R2L**, and **U2R**.
* **Real-time Confidence Metrics:** Calculates exact prediction probabilities for every packet.
* **Buffer Overflow Validation:** Built-in filter flags malformed headers and oversized payloads (> 1MB).
* **Lightweight Custom UI:** Built using Flask and Chart.js with an eye-soothing soft-warm aesthetic.
